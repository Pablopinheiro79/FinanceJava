# FinanceJava feiro com POO em Java

Sistema de controle de finanças pessoais
desenvolvido em Java.

## Funcionalidades

- Cadastrar receitas
- Cadastrar despesas
- Listar transações
- Consultar saldo da conta
- Validar dados informados pelo usuário

## Tecnologias

- Java
- Programação Orientada a Objetos (POO)
- Git e GitHub

## Objetivo

Projeto desenvolvido para aplicar conceitos
de Programação Orientada a Objetos durante
a graduação em Engenharia de Software.
